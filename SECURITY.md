# Security / 安全问题

Do not post credentials, enrollment codes, real usage databases, original transcripts or member
data in public issues. Use synthetic reproductions whenever possible.

For authentication or private-data vulnerabilities, use GitHub's private vulnerability reporting
feature when available. If unavailable, open a minimal issue asking for a private reporting channel,
without exploit details or personal data.

请勿在公开 Issue 中发布密钥、绑定码、真实用量数据库、原始对话或成员资料。
涉及身份验证或隐私漏洞时，优先使用 GitHub 私密漏洞报告；入口不可用时，先提交不含
漏洞细节的联系请求，由维护者提供私密渠道。

The 0.2.x source is the current development line. Releases are not commercially code-signed.
Check download hashes and retain bundled licenses. See [privacy](docs/PRIVACY.md) and
[acceptance](docs/ACCEPTANCE.md) for data boundaries and unverified scenarios.
