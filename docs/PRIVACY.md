# Privacy

未绑定的 `--run-once` 与 `--reconcile` 仅读取本机日志和原生数据库，不上传。
P2 已加入网络能力，仅在明确完成设备绑定后启用，服务器地址必须使用 HTTPS。

真实 USER_INPUT 和 PLANNER_RESPONSE 可由解析器在内存中读取，但不进入白名单结构、
终端日志、测试 Fixture 或版本控制。真实对账报告仅输出计数和是否匹配。

上传结构使用显式字段，不序列化原始 JSON。匿名 Session/Event 使用设备专属 HMAC。
四类 Token、模型名、UTC 时间、来源和 Step 序号是允许上传的元数据。

设备凭据在客户端通过当前用户范围的 DPAPI 保护，不提供明文降级。设备 Token 不接受
命令行传参，不写入普通日志。服务器只保存设备 Token 和一次性绑定码的 SHA-256 哈希。
本地读取故障不输出可能含路径或内容的原始错误。真实数据只能放在忽略目录 `.local/`。

解析器按行读取，仅保留模型设置和用量元数据，不在有序 Step 映射里保留对话正文。
上传结构严格使用白名单，顶层只有事件身份、模型、时间、来源和四类 Token 对象。
自动化测试含正文、提示词、OAuth 和路径 canary，确保它们不会进入序列化事件。

网络重定向被禁止，避免把设备凭据带到重定向目标；响应体限制 1 MiB，回执必须为成功
且数量覆盖完整批次才确认同步。队列和扫描状态不存原始 Session ID。

云端严格嵌套白名单拒绝正文、路径或额外身份字段，成员身份只来自设备认证。
网站经 Access 及 Worker 双重验证；普通成员可查全组，管理接口只允许管理员修改。
生产默认不加载演示数据；显式 ?demo=1 才展示合成数据并说明。备份位于私有忽略目录。


0.2.0 增加官方 CLI 的只读 /usage 调用，不由本程序读取 Google 登录凭据。未绑定的本地扫描不触发它，显式 --check-quota 可单独诊断。上传只含四个额度桶的比例和时间，以及扫描健康计数；不上传 CLI 原始输出或邮箱。
邮件只发送管理员指定目的地，包含异常窗口、成员在线情况和汇总估算，不含对话、原始会话或设备凭据。
